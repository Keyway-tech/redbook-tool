# 小红书图文帖发布检查清单

> 用途：步骤 11 落盘完成后，主 skill 按本清单逐项自查，未通过项如实提示用户（不阻塞交付）。
> 覆盖：封面首图 3 秒抓人、正文首屏、中段结构、CTA 位置、合规与来源、发布设置。

## 一、封面首图（3 秒抓人）

- [ ] 主标题 4–14 字（推荐 6–12），缩略图（列表小图）状态下 3 秒可读完、读懂
- [ ] 标题含钩子 / 痛点 / 认知冲突，不是陈述句口号
- [ ] 视觉层次清晰：标题 > 钩子 > 配图，不堆叠、无遮挡
- [ ] 字号对比与留白足够，小图不失焦
- [ ] 封面内容与正文一致，不标题党（完播率与信任双输）

## 二、正文首屏（黄金 5 秒）

- [ ] 前 2 句命中目标人群痛点 / 焦虑，无铺垫、无寒暄
- [ ] 首句即观点 / 反常识 / 数据冲击
- [ ] 前 3 句扫读无阻力：短句、无生僻词、无错别字
- [ ] 段落短（手机屏 ≤4 行/段），一行一个意思

## 三、中段与结构

- [ ] 逻辑骨架完整：观点 → 论证（带来源数据）→ 对错对照 → 行动收尾
- [ ] 每图一意，图文一致（逐图文案逐字呈现，不提炼）
- [ ] 热搜词自然融入 ≥2–3 处（非硬塞）
- [ ] 目录 / 总结页与正文页逐页对应、数量一致

## 四、CTA（末尾获客）

- [ ] 末尾钩子卡位于最后 1–2 张，动作单一清晰（进群 / 私信 / 评论区）
- [ ] 低门槛话术到位（如 19.9 一杯奶茶钱），利益点明确
- [ ] 双出口：答不上来 → 进群（转化）；答得上来 → 转发（传播）
- [ ] 评论区首评备好（补信息 / 引导互动 / 兜底转化）

## 五、合规与来源

- [ ] 数据与论点均有来源，无法验证的已标注「待核实」
- [ ] 网络取图已**图内标注来源**（摄影师 / 平台 / 授权类型）——用户指定强制规则
- [ ] `assets/SOURCES.md` 来源记录完整（文件、摄影师、平台、授权、URL）
- [ ] 无绝对化用语（最 / 第一 / 100% / 绝对）等违禁词自查
- [ ] 医疗 / 金融 / 承诺收益类表述合规自查（如适用）

## 六、发布设置

- [ ] 小红书发布标题 + 底部文字区完整文案就绪（非分页结构）
- [ ] 标签 3–5 个：垂类词 + 泛流量词，含目标人群搜索词
- [ ] 发布时间：工作日 12:00–13:00 / 18:00–21:00（中小企业老板活跃段）
- [ ] 图片尺寸 3:4（1080×1440），第 1 张为封面，共 n 张与目录对应
